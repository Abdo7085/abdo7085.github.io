About this product

The EAE IPI200 is a KNX IP interface that bridges the KNX bus to your local network, allowing installers to program and monitor KNX installations remotely using ETS over a standard Ethernet connection. Using the KNXnet/IP tunneling protocol, it provides a data link between the IP network and the KNX TP bus line — so there is no need for a USB dongle or direct physical connection to the bus during commissioning. At just 1 DIN module (18 mm) wide and entirely bus-powered, it adds IP connectivity to any KNX panel without consuming extra space or requiring an additional power supply. Green and orange LEDs indicate available and in-use tunneling connections at a glance.
